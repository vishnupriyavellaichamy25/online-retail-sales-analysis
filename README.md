# Online Retail Sales Analysis

## Project Overview

This project analyzes online retail sales data using Python, SQL, and Power BI to identify sales trends, top-performing products, and customer behavior.

## Tools Used

* Python (Pandas, NumPy, Matplotlib)
* SQL (MySQL)
* Power BI

## Dataset

The project uses the Online Retail dataset from the UCI Machine Learning Repository.

## Data Cleaning

* Removed duplicate records.
* Handled missing values.
* Removed cancelled transactions.
* Filtered invalid quantities and prices.
* Created a Revenue column.

## Dashboard Insights

* Total Revenue
* Total Orders
* Total Customers
* Quantity Sold
* Monthly Revenue Trend
* Revenue by Country
* Top Products
